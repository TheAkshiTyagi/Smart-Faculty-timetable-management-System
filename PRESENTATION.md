SMART FACULTY LECTURE & TIMETABLE MANAGEMENT SYSTEM

1. Problem
Students/faculty often need to manually inspect large timetables to answer who teaches what, where and when.

2. Solution
A searchable, role-based timetable platform with live lecture status and conflict detection.

3. Core Features
Teacher search | Class timetable | Live lecture | Free teachers | Free rooms | Conflict detection | CSV import | Weekly print/export | Natural-language query

4. Architecture
React + TypeScript -> FastAPI -> SQLAlchemy -> PostgreSQL

5. Demo
Student login -> search -> current lecture -> weekly timetable -> resources -> Admin conflict detection.

6. Future Scope
Automatic timetable optimization, ERP integration, attendance, notifications, mobile app, richer NLP.

Resume line:
Built a full-stack faculty lecture and timetable management system with JWT RBAC, PostgreSQL, real-time lecture lookup, resource availability, CSV ingestion, conflict detection, and deterministic natural-language timetable queries.
